# 毎日のルーティン

自分用のルーティン管理Webアプリです。GitHub Pagesに置くだけで動きます。サーバーやデータベースは必要ありません。

- 時間割どおりにチェックしていけるルーティン表（「早い日」と「遅い日」を切り替えられる）
- 行動手順書・ご褒美リスト・すき間時間リスト
- 4週間の記録と連続達成日数
- データはブラウザに自動保存。バックアップの書き出しと読み込みに対応
- スマホのホーム画面に追加すればアプリとして起動でき、オフラインでも動く

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（画面・動き・データ保存） |
| `manifest.webmanifest` | ホーム画面に追加したときのアプリ名やアイコンの設定 |
| `sw.js` | オフラインでも開けるようにするService Worker |
| `icon.svg` / `icon-192.png` / `icon-512.png` | アプリのアイコン |

## GitHub Pagesで公開する手順

1. GitHubで新しいリポジトリを作る（例：`routine`）。
2. このフォルダのファイルを、全部リポジトリの一番上の階層にアップロードする。
   - ブラウザなら「Add file」→「Upload files」で、ファイルをまとめてドラッグ＆ドロップ →「Commit changes」
   - コマンドなら次のとおり：
     ```bash
     git init
     git add .
     git commit -m "first commit"
     git branch -M main
     git remote add origin https://github.com/<ユーザー名>/routine.git
     git push -u origin main
     ```
3. リポジトリの「Settings」→「Pages」を開き、「Build and deployment」の Source を「Deploy from a branch」にする。Branch で `main` と `/ (root)` を選んで「Save」。
4. 1〜2分たつと `https://<ユーザー名>.github.io/routine/` で開けるようになる。

> 無料プランでは、GitHub Pagesを使うにはリポジトリを **Public** にする必要があります。コードは公開されますが、**チェックの記録などのデータは各ブラウザの中にだけ保存されるので、他の人からは見えません。**

## ホーム画面に追加する

- **iPhone（Safari）**：共有ボタン →「ホーム画面に追加」
- **Android（Chrome）**：メニュー →「ホーム画面に追加」または「アプリをインストール」
- **パソコン（Chrome / Edge）**：アドレスバー右側のインストールアイコン

## データの保存について

- チェックや編集をすると、その場でブラウザの `localStorage` に保存されます（キー名：`routine-v2`）。
- 保存先は「その端末の、そのブラウザ」だけです。スマホとパソコンでは記録が別々になります。
- 端末を移すときやバックアップしたいときは、右側の「データの保存」→「バックアップを書き出す」でJSONファイルを保存します。移した先で「バックアップを読み込む」を選べば元に戻ります。読み込んだ直後なら「元に戻す」で取り消せます。
- ブラウザの「履歴とサイトデータの削除」をするとデータも消えます。定期的にバックアップを書き出しておいてください。
- iPhoneのSafariでは、長いあいだ開かないとサイトのデータが消されることがあります。ホーム画面に追加したアプリとして使うと消えにくくなります。

## アプリを更新するとき

1. `index.html` などを書き換えてGitHubにアップロードする。
2. `sw.js` の1行目付近にある `CACHE = 'routine-v2'` の番号を1つ上げる（`routine-v3` など）。
3. アプリを一度閉じて開き直すと、新しい版に切り替わる。

保存されているデータは、更新しても消えません。
